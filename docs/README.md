# SaaS Maker documentation

This checked-in Markdown tree is the package and service documentation source.
It is validated directly with `pnpm check:docs`; there is no separate docs app
or deployment.

The public documentation covers the [ideas catalog](ideas.md),
@saas-maker/feedback, its project keys, and its small HTTP API. Private
portfolio operations belong to Site Health; reusable automation and skills
belong to SaaS Maker Tooling; App Health and CodeVetter remain independent
products. Those surfaces must not be documented here.

Start with [the quickstart](getting-started/quickstart.md).
